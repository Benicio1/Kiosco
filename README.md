# Antigravity full organizado

> **PROPÓSITO DE ESTE DOCUMENTO:**  
> Este archivo es la **portada y guía de uso para humanos**. Explica qué es el proyecto, cómo ponerlo en marcha y cómo colaborar, sin duplicar las reglas técnicas de la IA (que viven en `AGENTS.md`).

---


## 🚀 Inicio Rápido

* **Versión:** `v1.0.0` (SemVer)
* **Stack:** A definir según requerimientos (ver docs/PLAN.md)
* **Tipo:** web
* **Nivel de Scaffolding:** `ESTANDAR`
* **Contrato de Trabajo para IA y Equipo:** Ver [`AGENTS.md`](./AGENTS.md)
* **Historial de Versiones:** Ver [`docs/HITOS.md`](./docs/HITOS.md)

### 📂 Estructura Principal del Proyecto:
* `proyectos/` — Hub centralizado y categorizado de proyectos ([`proyectos/README.md`](./proyectos/README.md)): Web, Desktop, Extensiones, Gaming y Drivers.
* `src/` — Código fuente productivo del núcleo / integración.
* `docs/` — Documentación viva. Empezá por [`docs/README.md`](./docs/README.md) y [`docs/GUIA_DOCUMENTACION.md`](./docs/GUIA_DOCUMENTACION.md); incluye visión (`PLAN.md`), estado de avance (`ESTADO_ACTUAL.md`) y fallas (`BUGS.md`).
* `herramientas/` — Scripts utilitarios y servidor local.

### ⚙️ Comandos Rápidos:
* **`COMMITEAR.bat`** — Asistente interactivo paso a paso para hacer commits en Git local.
* **`SERVER.bat`** — Levanta el servidor local HTTP de desarrollo en un clic.
