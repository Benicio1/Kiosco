# ADR-0001: Elección del Stack Tecnológico Base

* **Fecha:** 2026-09-26
* **Estado:** Aceptado
* **Autor:** MÖLDEAstudio

---

## 1. Contexto y Problema
Al inicializar el proyecto se requiere definir el entorno de ejecución, lenguaje y herramientas principales para garantizar mantenibilidad, velocidad de desarrollo y compatibilidad con el equipo.

## 2. Decisión Tomada
Se adopta como stack principal: **Por definir (La IA sugerirá según la idea en docs/PLAN.md)**.

## 3. Consecuencias
* **Positivas:** Estandarización de herramientas, rápida curva de aprendizaje y soporte de automatizaciones locales.
* **Negativas / Compromisos:** Requiere mantener alineadas las versiones en las máquinas del equipo.

## 4. Alternativas Descartadas
* Mantener scripts dispersos sin stack unificado (descartado por falta de reproducibilidad y dificultad de mantenimiento).
