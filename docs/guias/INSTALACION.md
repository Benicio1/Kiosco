# Guía de Instalación y Configuración — Proyecto

> Instrucciones paso a paso para clonar, configurar el entorno y poner en marcha el proyecto.

---

## 1. Prerrequisitos
* **Node.js:** v20.0.0 o superior (`node -v`).
* **Git:** Instalado y configurado en tu terminal (`git --version`).
* **Editor:** VS Code / Antigravity / Cursor con soporte para Markdown y JavaScript.

---

## 2. Puesta en Marcha (Instalación Rápida)

```bash
# 1. Clonar el repositorio o abrir la carpeta
cd mi-proyecto

# 2. Instalar dependencias requeridas
npm install

# 3. Crear archivo de variables de entorno (si aplica)
cp .env.example .env

# 4. Iniciar el servidor local de desarrollo
SERVER.bat
```
