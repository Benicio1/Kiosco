# proyectos/web/ — Aplicaciones Web y Servicios

## Propósito
Alojar proyectos de aplicaciones web, portales, servicios REST y PWAs del ecosistema.

## Incluye
- Proyectos web con código fuente (`src/`, `public/`, configuraciones).
- `gastro-stock-pwa`: Sistema PWA de gestión de stock gastronómico (Next.js 14, React 18, Tailwind, Prisma).

## No incluye
- Carpetas de dependencias pesadas (`node_modules/`) ni builds temporales (`.next/`).
- Aplicaciones nativas de escritorio o extensiones de navegador.

## Proyectos
| Proyecto | Stack | Descripción |
|---|---|---|
| [`gastro-stock-pwa/`](./gastro-stock-pwa/README.md) | Next.js 14, React 18, Prisma, Tailwind CSS | PWA para control de stock gastronómico en tiempo real |
| [`lector-pdf-pwa/`](./lector-pdf-pwa/README.md) | HTML5, CSS3, ES Modules, PDF.js, PWA Offline | Lector móvil de PDFs con filtros de luz antifatiga visual (luz cálida, sepia, noche, OLED, e-Ink) |
