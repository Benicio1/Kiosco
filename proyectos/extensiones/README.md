# proyectos/extensiones/ — Extensiones de Navegador

## Propósito
Alojar extensiones para navegadores basados en Chromium (Brave, Chrome, Edge) y Firefox.

## Incluye
- Manifiestos de extensión (`manifest.json` Manifest V3).
- Scripts de fondo (*service workers* / `background.js`), *content scripts*, interfaces emergentes (*popups*) e iconografía.

## No incluye
- Proyectos web completos de backend ni aplicaciones de escritorio.
