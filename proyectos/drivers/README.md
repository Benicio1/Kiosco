# proyectos/drivers/ — Controladores y Configuración de Hardware

## Propósito
Centralizar paquetes de controladores (*drivers*), archivos de instalación (`.inf`, `.sys`, `.cat`) y scripts de despliegue para periféricos y dispositivos de hardware.

## Incluye
- Controladores empaquetados e instaladores automatizados por batch/PowerShell.
- Documentación de compatibilidad con Windows y hardware soportado.

## No incluye
- Código fuente de aplicaciones de usuario ni extensiones de navegador.
