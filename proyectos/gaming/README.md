# proyectos/gaming/ — Videojuegos y Modding

## Propósito
Centralizar proyectos vinculados al desarrollo de videojuegos, mods, mapas, plugins y assets interactivos.

## Incluye
- Código fuente de mods para Minecraft (Java, Fabric, Forge o NeoForge).
- Recursos de juego (texturas, modelos, JSONs de datos y recetas).
- Binarios empaquetados (`.jar`).

## No incluye
- Aplicaciones web ni utilidades de mantenimiento de Windows.

## Proyectos

|---|---|---|
| [`minecraft-mods/`](./minecraft-mods/README.md) | Minecraft Java | Colección de mods: Escuela Mod, Isaac Roguelike Mod y Villa Argentina Mod |
